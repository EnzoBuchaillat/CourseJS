# CourseJS

Exercices de JavaScript réalisés en cours de Développement Web (BUT 2 Informatique).

Chaque dossier correspond à un exercice indépendant : du HTML, du CSS et du JavaScript natif, sans framework ni dépendance.

## Exercices

| Exercice | Description | Notions travaillées |
| --- | --- | --- |
| [Shifumi](./shifumi) | Pierre, Feuille, Ciseaux contre l'ordinateur, avec compteur de score | `addEventListener`, `Math.random()`, `switch`, manipulation du DOM |

## Lancer un exercice

Aucune installation nécessaire : ouvrir le fichier `index.html` de l'exercice dans un navigateur.

```bash
git clone https://github.com/EnzoBuchaillat/CourseJS.git
cd CourseJS
open shifumi/index.html
```
